# MostNote 界面设计规范

## 风格基准

布局与交互参照 note_360 `master` 分支：左侧固定笔记栏、右侧全宽编辑器、独立标题、标签、工具栏与底部状态栏。
配色沿用 sb.sb 的浅灰页面、白色表面、细描边和黄色强调色。

界面保持扁平、紧凑、信息密度适中。**全站不使用圆角**，不使用大面积渐变、玻璃拟态或厚重投影。

## 颜色

| 用途 | 变量/值 |
| --- | --- |
| 页面背景 | `#f7f8fa` |
| 表面 | `#ffffff` |
| 次级表面 | `#f9fafb` |
| 主文字 | `#1c1c1e` |
| 次文字 | `#555a6a` |
| 弱文字 | `#6b6f7e` |
| 描边 | `#e0e2e8` |
| 细分隔线 | `#eef0f3` |
| 强调色 | `#ffd02f`（黄色，配深色文字） |
| 强调悬停 | `#f5c400` |
| 强调浅底 | `#fff4c4` |
| 危险色 | `#cd071e` |
| 危险浅底 | `#fdecef` |

深色主题使用中性深灰，不使用纯黑：背景 `#0f1115`，表面 `#16181d`，描边 `#262a31`，
主文字 `#e6e8eb`，次文字 `#9aa1ad`，强调色保持黄色。

## 字体与排版

- 字体栈：`system-ui, -apple-system, BlinkMacSystemFont, "Segoe UI", "PingFang SC", "Hiragino Sans GB", "Microsoft YaHei", "Helvetica Neue", Arial, sans-serif`。
- 基准字号 `15px`，行高 `1.6`。
- 标题字重 `600`，正文 `400`，按钮与表头 `600`。
- 全部使用系统字体，不加载 Google Fonts。
- 侧栏笔记标题单行截断，预览最多两行截断。

## 布局

- 顶栏：白色，`56px` 高，底部 `1px` 描边；仅保留品牌、同步状态和主题切换。
- 左侧笔记栏：固定 `300px`，`#f9fafb` 背景，右侧 `1px` 描边。
- **不设右侧详情栏**；笔记信息进入侧栏列表和编辑器底部状态栏。
- 主内容区：`#f7f8fa`，笔记页取消内边距，由编辑器白色表面铺满。
- 移动端：侧栏改为抽屉；主内容内边距收窄，输入与按钮保持至少 `40px` 触控高度。

## 组件

- 圆角：所有按钮、输入框、卡片、弹窗、标签、菜单均为 `0`，不设例外。
- 阴影：普通表面无阴影，仅下拉菜单、弹窗等浮层使用轻阴影。
- 按钮：`btn-primary` 为黄色底、深色文字；`btn-light` 为白底细描边；危险操作用浅红底红字，
  仅在确认弹窗中使用实心红。
- 侧栏工具区：搜索框、黄色全宽“新建笔记”按钮。
- 笔记列表：`NOTES` 表头带数量；选中项白色底 + `3px` 黄色左边框；显示标题、两行预览、标签和更新时间。
- 侧栏底部：用户头像、用户名、更多菜单；退出登录在菜单内，不单独占用底部空间。
- 编辑器：白色表面，顶部工具栏（保存状态、置顶、下载、分享、删除），独立标题输入，
  标签行，正文输入，底部状态栏（字数、标签数、修改时间）。
- 浮层：下拉、快速搜索、右键菜单、弹窗统一白底、细描边、无圆角。
- 空状态：无笔记时显示品牌标识、说明和新建按钮；同步中显示加载指示，不误报“暂无笔记”。
- 图标：统一使用 `client/src/components/Icon.js` 的 24×24 描边 SVG（1.75px、方形端点、`currentColor`），
  不再混用 Font Awesome 的实心/描边图标；侧栏用户菜单图标与文字间距 `10px`。
- 用户菜单：宽度与侧栏内容对齐，左右各留约 `8px`，菜单项使用统一图标、34px 行高和直角高亮。

## 实施约束

- 主题入口为 `client/src/scss/_variables.scss`、`_custom.scss`、`_dark.scss`。
- 全局设置 `$enable-rounded: false`，并显式覆盖 `border-radius: 0`。
- 深色主题必须与浅色主题同步维护，不能出现白底组件。
- 笔记数据包含 `title`、`content`、`tags`、`pinned`；标签保存为 JSON 数组。
- 同步前必须通过 `client/src/utils/note.js` 归一化旧缓存：空标题从正文首行派生，空标签转为 `[]`，
  避免旧版本本地笔记上传时触发 422（“Notes could not be synced”）。
- Gemini AI 功能未接入：缺少 `GEMINI_API_KEY` / `API_KEY`，不展示相关入口。
- 改动完成后必须构建，并在桌面与移动端截图检查，再执行登录回归测试。
