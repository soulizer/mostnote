# MostNote 界面设计规范

## 风格基准

整体参照 <https://sb.sb/>：浅灰页面、白色表面、细描边、紧凑排版、克制的阴影、黄色强调色。
界面保持扁平、清晰、信息密度适中，不使用大面积渐变、玻璃拟态或厚重投影。

## 颜色

| 用途 | 变量/值 |
| --- | --- |
| 页面背景 | `#f7f8fa` |
| 表面 | `#ffffff` |
| 次级表面 | `#fafbfc` |
| 主文字 | `#1c1c1e` |
| 次文字 | `#555a6a` |
| 弱文字 | `#6b6f7e` |
| 描边 | `#e0e2e8` |
| 细分隔线 | `#eef0f3` |
| 强调色 | `#ffd02f`（黄色，配深色文字） |
| 强调悬停 | `#f5c400` |
| 强调浅底 | `#fff4c4` |
| 危险色 | `#cd071e` |
| 危险浅底 | `#fdecef` |

深色主题使用中性深灰，不使用纯黑：背景 `#0f1115`，表面 `#16181d`，描边 `#262a31`，
主文字 `#e6e8eb`，次文字 `#9aa1ad`，强调色保持黄色。

## 字体与排版

- 字体栈：`system-ui, -apple-system, BlinkMacSystemFont, "Segoe UI", "PingFang SC", "Hiragino Sans GB", "Microsoft YaHei", "Helvetica Neue", Arial, sans-serif`。
- 基准字号 `15px`，行高 `1.6`。
- 标题字重 `600`，正文 `400`，按钮与表头 `600`。
- 全部使用系统字体，不再加载 Google Fonts 或等宽字体作为正文。

## 布局

- 顶栏：白色，约 `56px` 高，底部 `1px` 描边。
- 左侧笔记栏：白色，`250px`，右侧描边。
- 右侧详情栏：白色，`260px`，左侧描边。
- 主内容区：`#f7f8fa`，内边距 `16px 20px`。
- 移动端：主区内边距收窄，输入与按钮保持至少 `40px` 触控高度。

## 组件

- 圆角：输入框、按钮 `6px`；卡片、弹窗、编辑器 `10px`。
- 阴影：普通卡片无阴影，仅下拉菜单、弹窗等浮层使用 `0 10px 28px rgba(15, 23, 42, .14)`。
- 卡片：白底、`1px` 描边、无阴影；卡片头使用细分隔线。
- 按钮：`btn-primary` 为黄色底、深色文字；`btn-light` 为白底细描边；危险操作用浅红底红字，
  仅在确认弹窗中使用实心红。
- 表单：标签使用次文字色、`13px`、字重 `600`；聚焦时描边变为深色，不使用发光阴影。
- 侧栏导航：`8px 12px` 内边距、`6px` 圆角；选中项浅黄底、深色文字，并带 `3px` 黄色竖条。
- 编辑器：白色卡片，内边距 `24px 28px`，系统字体，行高 `1.7`。
- 浮层：下拉、快速搜索、右键菜单、弹窗统一白底、细描边、`8-12px` 圆角与轻阴影。

## 实施约束

- 主题入口为 `client/src/scss/_variables.scss`、`_custom.scss`、`_dark.scss`。
- 优先通过 SCSS 覆盖实现，不重写 React 结构；确需修改标记时保持现有类名与行为。
- 深色主题必须与浅色主题同步维护，不能出现白底组件。
- 改动完成后必须构建，并在桌面与移动端截图检查，再执行登录回归测试。
